Mouse

Drag to orbit · right-drag or Shift-drag to pan · scroll to zoom · click any object to inspect it.

Touch

One finger orbits · two fingers pinch to zoom and drag to pan · tap an object to select it.

Keyboard

Arrows orbit · W / S zoom · A / D pan · Space play or pause · F focus · R reset · / search · Esc close.

About the scales

Educational keeps every world visible while preserving order and rough spacing. Relative uses true size ratios and true distance ratios (the Sun is shrunk so Mercury stays outside it). Orbital speeds are compressed so distant worlds still move.
